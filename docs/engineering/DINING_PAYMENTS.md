# 餐飲後台付款明細

## 架構與程式邊界

TableCraft 後台沿用餐飲站台資料表工作區，新增付款資料集，讓後台依帳單辨識分帳付款金額、付款方式、序號及時間。資料來自 `dining_payments`，由既有分頁／搜尋 API 按組織過濾；不計算退款或宣稱金流實際結算。前台帳號或前台視圖不得讀取或搜尋付款明細；不同組織資料不得混入。前端沿用餐飲設計範本的表格容器及語言切換，不新增全域樣式。

## 測試

先以隔離組織建立本租戶與其他租戶付款資料；測試後台明細欄位與搜尋、前台視圖拒絕、其他租戶隔離，以及未登入拒絕。遠端 CI 驗證；無本機測試。此項是讀取能力，不改變付款交易或退款規則。
