# 電商模擬營運摘要

## 架構與邊界

MarketLane 後台營運摘要顯示同租戶模擬已付款總額、已記錄商品退款及兩者差額；付款總額含運費，商品退款不含運費，並非會計營收或實際金流。退款加總必須關聯同租戶已付款訂單及該訂單的明細；孤兒、跨租戶、錯誤訂單明細及未付款訂單的退款不得降低摘要。正常部分退款仍依既有累計退款規則計算。只讀取現有紀錄，不自動更改或刪除異常資料；前台或其他租戶不得讀取此摘要。

## 測試

先建立同租戶已付款訂單、明細及合法退款，另建立孤兒、未付款與錯配明細退款；驗證只扣除合法退款、總額保留運費，並沿用既有前台及跨租戶測試。僅在遠端 CI 執行。

## 模擬出貨

MarketLane 模擬出貨只允許已登入、可寫入且屬後台範圍的 Shop 使用者操作；查詢與更新均以目前租戶為界。僅付款狀態為 `paid` 且履約狀態為 `unfulfilled` 的訂單可以出貨。訂單履約狀態更新、tracking number、出貨紀錄、冪等回應與稽核紀錄必須在同一資料庫交易中提交；條件式狀態更新及訂單穩定 shipment ID 保證重複與並發請求不會建立多筆出貨。相同冪等鍵只接受相同請求內容，其他內容回傳衝突。這是模擬物流，沒有外部承運商或實際寄送。

出貨邊界先驗證未付款及只讀／前台角色不會寫入、跨租戶訂單不可見、同租戶後台操作可出貨、相同冪等請求重播回傳原結果、同鍵異內容衝突，以及同訂單併發請求只留下單筆出貨。測試只在遠端 CI 執行。
